# SECURE-LOW-POWER-RADIO-COMMUNICATION-PROTOCOL-OVER-LoRa-Durbhaash-
Durbhaash is a secure, low-power offline messaging system using ESP32-S3 and SX1262 LoRa. It features AES-128-GCM encryption, ACK, automatic retries, replay protection, OLED display and a Wi-Fi web interface. Tested range: 3.5 km with obstacles and 4 km line of sight.
